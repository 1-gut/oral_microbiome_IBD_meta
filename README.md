# Oral microbiome meta-analysis in IBD

This repository contains the complete workflow used for a pooled meta-analysis of oral microbiome sequencing data in inflammatory bowel disease (IBD).  

The workflow covers raw 16S rRNA sequencing data retrieval, primer removal, processing and taxonmic assignment using the nf-core ampliseq pipeline, and downstream and machine learning analyses.

---

## 1. Raw data retrieval using nf-core/fetchngs

Raw sequencing data were retrieved from public repositories using the **nf-core/fetchngs** pipeline.

- BioProject accessions are listed in:  
  `data/raw/bioproject_accessions_list.csv`
- Software versions (Nextflow, nf-core, etc.) are recorded in:  
  `workflow/env/versions.txt`

### nf-core fetch-ngs command

```bash
nextflow run nf-core/fetchngs \
   -profile <docker/singularity/.../institute> \
   --input accession_list.csv \
   --outdir <OUTDIR>
```
---
## 2. Primer removal

Primer sequences were removed prior to amplicon processing using cutadapt.
Different primer sets were handled separately using dedicated scripts.

All preprocessing and downstream analyses use the same conda environment.

Create and activate the conda environment:

```bash
conda env create -f workflow/env/environment.yml
conda activate oral_microbiome_IBD_meta
```

### Primer removal scripts

Primer removal scripts are located in the workflow/ directory:

```
01_Ab_primer.sh   # Primer set Ab
02_Mo_primer.sh   # Primer set Mo
03_Xi_primer.sh   # Primer set Xi
```

Each script applies primer trimming to the relevant subset of fastq files.

---

## 3. 16S rRNA sequencing data processing and taxonomy assignment with nf-core/ampliseq

After primer removal, sequences were processed and taxonomy assigned using the nf-core/ampliseq pipeline.
- Pipeline was run on the Eddie HPC (University of Edinburgh) cluster
- Custom Eddie configuration file: `workflow/eddie.config`

### Run ampliseq

The nf-core run command is in:

`workflow/04_nfcore_ampliseq_command.sh`


### Key outputs

```bash
ampliseq_out/
├── dada2/
│   └── DADA2_stats.tsv
├── input/
│   └── oral_metadata.tsv
├── phyloseq/
│   └── dada2_phyloseq.rds
└── picrust/
    └── METACYC_path_abun_unstrat_descrip.tsv
```

These files are used for downstream analyses.

## 4. Downstream analysis

All downstream analyses were conducted in R using the scripts in the `analysis/` directory.

## Shared R utilities

```bash
R/
├── packages.R # Loads required R packages and versions
└── functions_phyloseq.R # Reusable helper functions for phyloseq-based analyses
```

### Analysis scripts (execution order)

- `analysis/00_config.R` — Global configuration (paths, parameters, plotting options)  
- `analysis/01_import_process_build.R` — Import ampliseq outputs and construct phyloseq objects  
- `analysis/02_fig1B_study_sample_details.R` — Study- and sample-level descriptive statistics (Figure 1B)  
- `analysis/03_fig2A_hedges_smd.R` — Meta-analysis of alpha diversity using Hedges’ SMD (Figure 2A)  
- `analysis/04_figs2BCD_diversity_analysis.R` — Alpha and beta diversity analyses (Figures 2B–D)  
- `analysis/05_figs3A_S9_maaslin2.R` — Differential abundance analysis using MaAsLin2 (Figures 3A + S9)  
- `analysis/06_fig3B_network_analysis.R` — Network analysis (Figure 3B)  
- `analysis/07_figs4AB_picrust_analysis.R` — PICRUSt2 MetaCyc pathway analysis (Figures 4A + B)
- `analysis/08_figS8_beta_continent.R` — Continent-stratified beta diversity (Figure S8)  
- `analysis/09_export_ml_abundance_table.R` — Export abundance tables for machine learning
